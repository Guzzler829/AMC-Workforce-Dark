# A Dark Mode for AMC Theatres' Workforce by infor

## If you're employed by AMC Theatres, and you hate the infor.com UI and light mode as much as I do, then this is for you.

### Changes to the UI
- (Mostly) site-wide dark mode. Some fields will still have a white background. If you happen to come across some important text that is illegible because the background is still white, simply right click on the area and click "Inspect (Q)", then look in the inspector to see where your text is. It will probably look like <b>\<th class="etmContentMenu">Text on the webpage\</th></b>
- When you have 0 messages, the icon with the number 0 disappears entirely instead of displaying a 0 in the icon. Instead of "Messages [0]", the tab just says "Messages".
- Made some of the tiny font more legible by enlarging it.
- Changed the ugly, chartruce color highlight for the current day on your personal schedule.
- <b>Added color coding to the team schedule</b>, and created a collapsible menu displaying all kitchen managers and cooks and their respective shifts for <b>the current day</b>.

## How to use:

- Install Firefox if you don't have it
- Install the FireMonkey browser extension. (https://addons.mozilla.org/en-US/firefox/addon/firemonkey/)


#### File import method 1 (recommended):
- Download or clone this repository to get the .js and .css files
- Add the files in FireMonkey by clicking "Import" at the bottom left, and then selecting the files.

#### File import method 2:
 If for some reason you can't import the files, you can also click on each file listed on at the top of this page, then, in the top bar above the code, click the button that says "Raw". On the page it directs you to with the raw code (example: https://raw.githubusercontent.com/Guzzler829/AMC-Workforce-Dark/refs/heads/master/AMC%200%20messages.user.js), FireMonkey will automatically make a box at the top of the page that asks if you want to install the script.
 - Click install, and FireMonkey will automatically install the script
 - Repeat this for each individual file (unfortunately)
